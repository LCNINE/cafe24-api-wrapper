# cafe24-api-typescript
 
카페24 API를 타입스크립트 환경에서 편리하게 사용할 수 있도록 하는 라이브러리입니다.

## 구현된 API
- [ ] 상점 (Store)
- [ ] 상품 (Product)
- [ ] 주문 (Order)
- [ ] 회원 (Customer)
- [ ] 게시판 (Community)
- [ ] 디자인 (Design)
- [ ] 프로모션 (Promotion)
- [ ] 앱 (Application)
- [ ] 상품분류 (Category)
- [ ] 판매분류 (Collection)
- [ ] 공급사 정보 (Supply)
- [ ] 배송 (Shipping)
- [ ] 매출통계 (Salesreport)
- [ ] 개인화정보 (Personal)
- [ ] 개인정보 (Privacy)
- [ ] 적립금 (Mileage)
- [ ] 알림 (Notification)
- [ ] 번역 (Translation)
- [ ] 접속통계 (Analytics)
